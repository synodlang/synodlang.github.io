# Synod documentation

Synod is a small language for watching distributed systems think. You write the
nodes, the messages and the faults; the simulator runs them; you watch what
happened and check what must never happen.

Everything on these pages runs the same `synod` that you install on your machine,
compiled to WebAssembly: edit a program, press Run, and read the diagnostics or
watch the animation. If you are new, start with the tutorial; it builds up from one
sentence to a working Raft election.
