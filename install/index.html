Install Synod

Get the synod command. Latest release: checking…

macOS

Homebrew

brew install synodlang/tap/synod

install.sh

curl -fsSL https://synodlang.github.io/install.sh | sh

Installs to ~/.local/bin. Set SYNOD_INSTALL to change it, SYNOD_VERSION to pin a version.

Direct download

  • Universal (Intel and Apple silicon)
  • Apple silicon (arm64)
  • Intel (amd64)

Linux

Homebrew

brew install synodlang/tap/synod

install.sh

curl -fsSL https://synodlang.github.io/install.sh | sh

Installs to ~/.local/bin. Set SYNOD_INSTALL to change it, SYNOD_VERSION to pin a version.

Direct download

  • x86-64 (amd64)
  • arm64

Windows

Scoop

scoop bucket add synodlang https://github.com/synodlang/scoop-bucket
scoop install synod

Direct download

  • x86-64 (amd64), synod.exe in a .zip
  • arm64, synod.exe in a .zip

Go

go install

go install github.com/synodlang/compiler/cmd/synod@latest

Puts synod in $(go env GOPATH)/bin.

Verify

synod version

Unsigned binaries

The binaries are not signed yet. Package managers and install.sh avoid the warnings below.

  • macOS, file downloaded in a browser: xattr -d com.apple.quarantine ./synod
  • Windows SmartScreen: choose “More info”, then “Run anyway”.

All downloads and SHA256SUMS are on GitHub Releases.
